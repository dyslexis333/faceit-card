# Match room / dyslexis

Одностраничный игровой дашборд для практического задания 2. Проект использует ES6-модули и ООП: `UIComponent` отвечает за жизненный цикл и очистку обработчиков, API-компоненты и `ToDoWidget` наследуют его, а `Dashboard` управляет коллекцией виджетов.

## Запуск

Из папки проекта запустите любой статический сервер, например `python -m http.server 8080`, затем откройте `http://localhost:8080`.

## API

- `dummyjson.com/quotes/random` — игровая цитата (виджет показывает загрузку, успех и ошибку).
- `api.github.com/users/dyslexis333` — открытый внешний сигнал профиля (репозитории и подписчики).

Запросы используют `AbortController`; данные API вставляются через `textContent`, а `destroy()` отменяет активные запросы и снимает слушатели. Кнопка «Добавить список задач» создаёт независимый `ToDoWidget`, где можно добавлять, отмечать и удалять задачи.

Персональные значения ELO и матчей в макете указаны как презентационный срез профиля Faceit и сопровождаются ссылками на Faceit и Faceit Analyser.

## Журнал применения ИИ

ИИ использовался для генерации структуры интерфейса, модульного JavaScript и CSS. Архитектура, источники API и тексты проверены вручную.
